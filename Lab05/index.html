CCBC Website UI/UX Evaluation

This evaluation will assess the user's interface, the design, navigation,accesibility and the experience of the CCBC website.

1. Website URL

The URL for the CCBC website is: https://www.ccbcmd.edu

2.The Name of the Website

The name of the website is: Community College of Baltimore County

3. Target Audience

The target audience for the website are the prospective students,Students who currently attend CCBC, faculty and staffs and the People looking for educational programs and services. .

4. Website Organization

The website is organized into various main sections such as: Home, Admissions, Campus Life, About, Contact Us, and Academics. Each one of these sections includes important and valid resources and subpages for their target audience.

5. CRAP Design Principles

The CRAP design principles are Contrast, Repetition, Alignment, and Proximity,and the CCBC website uses each of these principles to perfectly build a user-friendly experience. The website make use of contrast which is one of the principles to create user-friendly interest and highlight crucial information. Repetition is used to create a look that is consistentand all through the site. Alignment can also be utilized in creating a sense of organization and a sense of order, while the proximity is used to when classifying or grouping together informations that are similar.

6. Accessibility Checker

The tool I used is the WAVE Web Accessibility Evaluation Tool. While, the aim score was a 9 out of 10 The wave Accessibility Checker identified 5 errors. The errors identified in the accessibility checker are one form label that's empty,two ARIA references broken and two alternative text errors missing.

7. The Website Effectiveness

The website is effective in giving informations to its target audience,about student services,admissions and academic programs. The website is quite easy for users to find several categories of information also the information is well-organized and easy to comprehend. The accessibility errors identified by the WAVE accessibility checker could cause some elements to be more difficult for some users to use.e.g. users with disabilities.

8. Website efficiency

The website is efficient in terms of navigation menus and its performance generally. It aswell provides smooth navigations while using the website,also a good user experience with little delays which could take extra time..

9. Website Engagement

The website looks so professional and it presents information vividly. It is engaging in terms of the website's content. HOowever, it assists the students to feel more confident about getting informations on educational resources. The website also provides interactive elements such as videos and links that can keep theusers engaged in the contents.

10. Recommendation for Improvement

My Recommendation for Improvement is that the CCBC should address and fix the accessibility errors that was identified by the WAVE accessibility checker. This allows the website to be much more accessible to even users with disabilities and also assist in improving the experience of the users generally. In addition, the website might even benefit from more interactive elements through surveys to help gather feedback and engage with users.
